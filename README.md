# HomeSpawnPlugin
Einfaches Minecraft Plugin für Minecraft 26.1.2 Paper Server.
Zur Installation muss ein Maven Build ausgeführt werden. Die Java Version ist 25.
 
## Verfügbare Commands:
- `/sethome` - Setzt dein Zuhause
- `/home` - Teleportiert dich nach Hause
- `/clearhome` - Löscht dein Zuhause
- `/clearhomes` - Löscht die Homes aller Spieler
- `/spawn` - Teleportiert dich zum Spawn
